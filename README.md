A program that writes exactly one deadpan weather forecast line — 156 characters — for Quibbleford, a city that does not exist, to `/output/entry.txt` for make.fun's "Deadpan Forecasts for Cities That Do Not Exist" bounty, $2 in USDC, winner takes all. The line was picked from a scored shortlist against the judge's own yardsticks (on-subject forecast first, then funnier, more vivid, broadcast tone, use of characters): overnight fog thickens into custard by 2 a.m., visibility three feet, low of 4 degrees — and drivers should bring a spoon. The output is fully deterministic: the same line every run.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (override with `OUTPUT_DIR` for local runs).
